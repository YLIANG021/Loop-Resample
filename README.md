# 👉Loop Resample👈

### 一条滚轮：改段数、捋曲线、摊点距。

在编辑模式里选中一段边，右键进入 **Loop Resample**，滚轮往上就加一段、往下就减一段，网格当场跟着变。改完不用重展 UV、不用补权重——UV、接缝、顶点色会尽量跟着新网格留下来。

## ✨ 用 Loop Resample 你可以

- 🖱️ 右键直接进入，滚轮实时改段数，左键留下、右键反悔
- 🔗 开口的边链、闭合的一整圈都能改，端点和接缝待在原地
- 🌊 Shift + 滚轮捋顺曲线，捋的同时环不缩水
- 📏 Ctrl + 滚轮把点摊匀，滚几下就是一排间距一致的点
- 🧲 UV、接缝、硬边、折痕 / 倒角权重、顶点颜色、顶点组权重尽量跟着重建
- 🌀 极点扇形也认，只选一段弧也能重排

## 📍 插件位置

在编辑模式下选中顶点或边，在 3D 视口里 `右键` → **Loop Resample**。

菜单名在任何语言下都保持英文 **Loop Resample**，好认；悬浮说明会跟着 Blender 界面语言走。

支持 English、简体中文、繁體中文、日本語、한국어、Deutsch、Français、Español、Italiano、Polski、Português、Русский、Tiếng Việt。

## 1. 不闭合的一段边，也能直接改

选一条开口的边链，滚轮改它的段数。两头钉在原处不动，中间的点按新的段数重新摊开，所以挨着它的那片面带不会被牵动——加一段不会把旁边的布线拧歪，减一段也不会把 UV 扯到别的岛上。

## 2. 闭合的一整圈，滚轮说了算

一整圈闭合的边走的是同一条路：滚轮决定这一圈切成几段，起点那个顶点留作锚点，接缝回到自己原来的位置。多一段、少一段都是整圈重新摊开，不会留出豁口，也不会悄悄转位。

<img width="810" height="480" alt="环形边功能展示" src="" />

## 3. Shift + 滚轮：顺手把曲线捋顺

按住 Shift 再滚，每滚一下顺一点。动的是曲线的弯，不是把点往中间塌，所以一圈捋顺了长度还在原来的地方，端上接着的布线也不会被拽走。想收手，右键一次性回到进入之前。

<img width="810" height="480" alt="smooth 展示" src="" />

## 4. Ctrl + 滚轮：把点摊匀

按住 Ctrl 再滚，每滚一下匀一点。原本疏密不均的曲线，滚几下就变成一排间距一致的点，后面接倒角、走线都省事。

## ⌨️ 操作一览

| 输入 | 作用 |
| --- | --- |
| 滚轮 | 加 / 减段数 |
| Shift + 滚轮 | 更平滑 |
| Ctrl + 滚轮 | 更均匀 |
| 左键 | 保留结果 |
| 右键 | 还原到进入前 |

段数、平滑、均匀这三个方向互不干涉，先滚哪个、后滚哪个，落下来的网格是一样的；右键一次全部退回。

## 🧩 属性怎么办

重建之后的网格不是裸的：UV、接缝、硬边、折痕和倒角权重、顶点颜色、顶点组权重，都会尽量按原来的位置算到新的顶点和边上。跨接缝的 UV 会按岛的边界来处理，不会把两个岛画到一条线上。

这里说的是"尽量"，不是"保证"——段数变化越剧烈，越可能有属性落不回原位，实机看一眼最准。

形态键（Shape Key）、自定义属性层和皮肤标记（Skin）不在处理范围内。
